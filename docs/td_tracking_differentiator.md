>
> 本文档面向数学基础薄弱的读者，所有推导都从最基础的概念开始，配合直觉解释和生活类比。

## 一、为什么需要 TD？——从一个问题说起

### 1.1 问题：阶跃指令会让飞机抖

当飞手推杆或姿态控制器给出一个新的角速度期望值时，这个值通常是**突变的**（数学上叫「阶跃」）：

```
期望角速度
  ↑
  │         ┌──────────
  │         │
  │─────────┘
  └──────────────────→ 时间
     t=0 处突变
```

如果控制器直接拿这个突变信号去跟踪，会产生**巨大的误差跳变**，导致：
- 控制输出瞬间饱和（电机吃满推力）
- 机体产生振荡和超调
- 就像你开车时**猛打方向盘**，车会摆来摆去

### 1.2 解决方案：用 TD 把阶跃「揉」成平滑曲线

TD（Tracking Differentiator，跟踪微分器）的作用就是一个**智能滤波器**：

```
       阶跃输入              TD 输出
  ↑                    ↑
  │     ┌──────       │        ╭──────
  │     │             │       ╱
  │─────┘             │──────╯
  └──────→ t          └──────────→ t
  突变，不可导          平滑，可导，可以求加速度
```

**生活类比**：TD 就像一个**老司机**——
- 目的地突然变了（阶跃），他不会猛踩油门急转弯
- 而是**先加速、再匀速、最后减速**平稳到达
- 并且能自动计算出当前需要多大的速度和加速度

### 1.3 TD 比普通低通滤波器好在哪？

| 特性 | 普通低通滤波 | TD 跟踪微分器 |
|------|-------------|--------------|
| 延迟 | 有固定延迟 | 几乎无延迟（非线性快追） |
| 超调 | 可能超调 | **无超调**（远处快追、近处柔停） |
| 导数 | 噪声放大严重 | 天然输出平滑的导数（加速度） |
| 响应 | 误差大小同速 | **误差大→快追，误差小→慢停** |

## 二、TD 的三层状态——像三层楼

TD 内部维护三个状态变量，它们有严格的**积分关系**：

```
_T4 (jerk，加加速度)
  │
  │  积分 ∫dt
  ▼
_x3 (加速度)  ──────→ 控制律用作前馈
  │
  │  积分 ∫dt
  ▼
_x2 (角速度)  ──────→ 控制律用作期望值
  │
  │  积分 ∫dt
  ▼
_x1 (角度)    ──────→ 本算法中未直接使用
```

### 2.1 数学表达

状态更新的微分方程：

$$
\dot{x}_1 = x_2 \quad \text{（角度的变化率 = 角速度）}
$$

$$
\dot{x}_2 = x_3 \quad \text{（角速度的变化率 = 角加速度）}
$$

$$
\dot{x}_3 = T_4 \quad \text{（角加速度的变化率 = jerk）}
$$

**代码中的离散化**（欧拉积分）：

```cpp
_x1 += _x2 * dt;   // x1[k+1] = x1[k] + x2[k] × dt
_x2 += _x3 * dt;   // x2[k+1] = x2[k] + x3[k] × dt
_x3 += _T4 * dt;   // x3[k+1] = x3[k] + T4[k] × dt
```

### 2.2 直觉解释

想象你在高速公路开车：
- **_x1**（位置）：你在哪里
- **_x2**（速度）：你开多快 ← **TD 的主要输出**
- **_x3**（加速度）：你踩油门/刹车的力度 ← **TD 的辅助输出（前馈）**
- **_T4**（jerk）：你踩油门的速率（越快越猛烈）

TD 的任务就是：**计算出合适的 _T4（踩油门的速率）**，让 _x2 平滑地追上期望值。

## 三、核心数学工具——smoothKp 非线性增益

在理解 TD 的具体步骤之前，先理解它最核心的数学工具。

### 3.1 为什么不用普通增益？

普通比例控制：`输出 = K × 误差`

问题：
- K 大 → 跟踪快，但近处超调
- K 小 → 不超调，但远处跟踪慢

**我们想要的是**：K 随误差自动调整！

### 3.2 smoothKp 的数学定义

```
smoothKp0(e, P, r) = r × tanh(P/r × e)
```

其中：
- `e`：误差大小（标量，≥0）
- `P`：增益参数（越大跟踪越快）
- `r`：饱和半径（限制输出最大值）
- `tanh`：双曲正切函数

### 3.3 tanh 函数速查

如果你不熟悉 tanh，它长这样：

```
tanh(x)
  1 ┤               ─────────────
    │             ╱
    │           ╱
  0 ┤─────────╱──────────────────
    │       ╱
    │     ╱
 -1 ┤────────────────
    └────────────────────────────→ x
        -3  -2  -1   0   1   2   3
```

关键性质：
- **x 很小时**：`tanh(x) ≈ x`（近似线性）
- **x 很大时**：`tanh(x) ≈ 1`（饱和到 1）
- **总是在 -1 和 +1 之间**

### 3.4 smoothKp 的行为

把 tanh 的性质代入 `smoothKp0(e) = r × tanh(P/r × e)`：

**当误差 e 很小时**：
```
tanh(P/r × e) ≈ P/r × e     （因为 tanh(x)≈x 当 x 很小）
smoothKp0 ≈ r × (P/r × e) = P × e
```
→ 输出 ≈ P × e，即**普通比例控制**

**当误差 e 很大时**：
```
tanh(P/r × e) ≈ 1            （因为 tanh(x)≈1 当 x 很大）
smoothKp0 ≈ r × 1 = r
```
→ 输出 ≈ r，即**饱和限幅**

**完整的行为曲线**：

```
输出
  r ┤ · · · · · · · · ─────────  ← 大误差时饱和在 r
    │              ╱
    │           ╱
    │        ╱        ← 过渡区：平滑连接
    │     ╱
    │  ╱              ← 小误差时线性：斜率 = P
  0 ┤╱
    └────────────────────────→ 误差 e
```

### 3.5 对比：线性增益 vs smoothKp

```
输出
    │     线性 K×e          smoothKp
    │        ╱               ─────── r
    │       ╱            ╱
    │      ╱          ╱
    │     ╱        ╱
    │    ╱      ╱
    │   ╱    ╱
    │  ╱  ╱
    │ ╱╱
  0 ┤╱
    └────────────────────→ 误差 e
```

- 线性增益：大误差时输出无限大 → 饱和 → 超调
- smoothKp：大误差时自动限幅 → 不饱和 → **无超调**

### 3.6 代码实现

```cpp
// smoothKp0: 只返回值
float RateTd::smoothKp0(float error, float P, float r)
{
    float x = P / r * error;
    float tanh_x = tanhf(x);
    return r * tanh_x;       // r × tanh(P/r × e)
}
```

### 3.7 smoothKp1: 带导数版本

smoothKp1 除了返回函数值 d0，还返回时间导数 d1：

```
d0 = r × tanh(P/r × e)              ← 和 smoothKp0 一样
d1 = d(d0)/dt = P × sech²(P/r × e) × ė
```

其中 `sech²(x) = 1 - tanh²(x)`，`ė` 是误差的时间导数。

**为什么需要导数？** → 第二层（加速度跟踪）需要知道目标加速度在怎么变化，这个变化率就要用到 d1。下面会详细解释。

#### 导数推导过程（可跳过）

设 `f(t) = r × tanh(P/r × e(t))`，求 `df/dt`：

```
df/dt = r × d[tanh(P/r × e)] / dt          // 提出常数 r
      = r × sech²(P/r × e) × d(P/r × e)/dt // 链式法则
      = r × sech²(P/r × e) × (P/r) × ė     // 提出常数 P/r
      = P × sech²(P/r × e) × ė              // 化简
```

代码：
```cpp
SmoothKpD1 RateTd::smoothKp1(float error, float error_dot, float P, float r)
{
    float x = P / r * error;
    float tanh_x = tanhf(x);
    float sech2_x = 1.0f - tanh_x * tanh_x;  // sech²(x) = 1 - tanh²(x)

    result.d0 = r * tanh_x;              // 函数值
    result.d1 = P * sech2_x * error_dot; // 时间导数
    return result;
}
```

## 四、track2() 逐步详解

现在我们把所有工具组合起来，逐步理解 `track2()` 函数。

### 4.0 总览：两层嵌套跟踪

TD 内部其实是**两层嵌套的跟踪回路**：

```
                     ┌──────────────────────────┐
  expect ──→ 速度层  │ e2 → smoothKp1 → T3      │──→ 加速度层 ──→ T4 → ∫→ x3 → ∫→ x2
  (期望)     (第一层) │                           │    (第二层)
                     └──────────────────────────┘
```

- **第一层（速度层）**：计算 "x2 要追 expect，需要多大的加速度 T3？"
- **第二层（加速度层）**：计算 "x3 要追 T3，需要多大的 jerk T4？"

就像：
- 导航说"你要加速到 80km/h"（T3）
- 你的脚控制"踩多深油门"（T4）来实现加速

### 4.1 步骤 1：计算速度跟踪误差

```cpp
Vector3f e2   = expect - _x2;    // 速度误差向量（三轴）
Vector3f e2_1 = -_x3;            // 速度误差的时间导数
```

#### 数学解释

**e2 很好理解**：期望 - 实际 = 误差

**e2_1 为什么是 -_x3？** 推导如下：

```
e2 = expect - x2

对两边求时间导数:
ė2 = d(expect)/dt - d(x2)/dt

因为 expect 在一个周期内视为常数: d(expect)/dt = 0
因为 x2 的导数就是 x3: d(x2)/dt = x3

所以: ė2 = 0 - x3 = -x3
```

### 4.2 步骤 2：向量误差 → 标量误差

三轴是三个独立的轴，误差是一个三维向量。但 smoothKp 只能处理标量。怎么办？

**解法：先算模长，用 smoothKp 处理标量，再乘回方向。**

```cpp
float e2_length = safeSqrt(e2.norm_squared());  // |e2| = √(ex² + ey² + ez²)
```

**为什么不三轴分别处理？**
- 因为三轴耦合（Roll 和 Pitch 同时有误差时，总加速度能力是有限的）
- 用向量模长可以正确分配各轴的加速度份额

### 4.3 步骤 3：计算模长的时间导数

```cpp
e_1_n = e2(0)*e2_1(0) + e2(1)*e2_1(1) + e2(2)*e2_1(2);  // 点积

if (!isZero(e2_length)) {
    e_1 = e_1_n / e2_length;  // d|e2|/dt
}
```

#### 数学推导

`|e2|` 是一个标量函数：`|e2| = √(e2 · e2)`

对时间求导（用链式法则）：

```
d|e2|/dt = d√(e2·e2) / dt

        = 1/(2√(e2·e2)) × d(e2·e2)/dt        // √x 的导数是 1/(2√x)

        = 1/(2|e2|) × 2(e2 · ė2)              // 点积求导

        = (e2 · ė2) / |e2|                     // 化简
```

所以：`e_1 = (e2 · e2_1) / e2_length`

**直觉理解**：
- 当 e2 和 ė2 同向（误差在增大）→ e_1 > 0 → 模长在增大
- 当 e2 和 ė2 反向（误差在减小）→ e_1 < 0 → 模长在减小
- 当 ė2 垂直于 e2（误差在转向）→ e_1 = 0 → 模长不变

### 4.4 步骤 4：用 smoothKp1 计算目标加速度（标量）

```cpp
SmoothKpD1 d2 = smoothKp1(e2_length, e_1, _P2, _r3);
```

- **输入**：误差模长 `|e2|`、模长导数 `e_1`、增益 `P2`、半径 `r3`
- **输出**：
  - `d2.d0 = r3 × tanh(P2/r3 × |e2|)` → 目标加速度的**大小**（标量）
  - `d2.d1` → 上述的时间导数

**物理含义**：
```
d2.d0 就是「需要多大的加速度才能追上期望角速度」

  误差 |e2| 大 → d2.d0 ≈ r3（最大加速度，全力追）
  误差 |e2| 小 → d2.d0 ≈ P2 × |e2|（小加速度，轻柔停）
```

### 4.5 步骤 5：标量→向量还原（构造 T3 和 T3_1）

现在 d2.d0 只是一个大小，需要乘以**方向**才能得到三轴向量：

```cpp
Vector3f n   = e2 * (1.0f / e2_length);          // 单位方向向量
Vector3f n_1 = (e2_1*e2_length - e2*e_1)          // n 的时间导数
               / (e2_length * e2_length);

T3   = n * d2.d0;                                 // 目标加速度向量
T3_1 = n * d2.d1 + n_1 * d2.d0;                   // T3 的时间导数
```

#### 4.5.1 单位向量 n

```
n = e2 / |e2|
```

这就是误差的**方向**。比如 e2 = [3, 4, 0]，则 |e2| = 5，n = [0.6, 0.8, 0]。

**意义**：加速度应该**朝着误差的方向**施加，才能最快减小误差。

#### 4.5.2 n 的时间导数 n_1

n 是一个单位向量，但它的方向会随时间变化（因为 e2 在变）。n_1 就是方向的变化率。

**推导**（商法则）：

```
n = e2 / |e2|

dn/dt = d(e2/|e2|) / dt

      = (ė2 × |e2| - e2 × d|e2|/dt) / |e2|²     // 商法则：d(A/B) = (A'B - AB') / B²

      = (e2_1 × e2_length - e2 × e_1) / (e2_length²)
```

**直觉理解**：
- 如果误差方向不变（直线追踪），n_1 = 0
- 如果误差在转弯（比如从追 Roll 变成追 Pitch），n_1 ≠ 0

#### 4.5.3 T3 和 T3_1

```
T3 = n × d2.d0    → 「朝这个方向，以这个大小加速」
```

T3_1 是 T3 的时间导数，用**乘积法则**：

```
d(T3)/dt = d(n × d2.d0)/dt
         = dn/dt × d2.d0 + n × d(d2.d0)/dt      // 乘积法则
         = n_1 × d2.d0 + n × d2.d1               // 代入
```

**为什么需要 T3_1？** → 因为第二层（加速度跟踪）需要一个**前馈项**。

前馈的意思是：「即使当前 x3 已经等于 T3，但如果 T3 本身在变化，x3 也需要跟着变。T3_1 就是这个变化量。」

### 4.6 步骤 6：第二层——加速度跟踪

```cpp
Vector3f e3 = T3 - _x3;                          // 加速度误差
float e3_length = safeSqrt(e3.norm_squared());    // 加速度误差模长
float d3 = smoothKp0(e3_length, _P3, _r4);       // jerk 反馈量（标量）
```

这一层的结构和第一层类似，但更简单（不需要导数）：

```
第一层: 速度误差 e2 → smoothKp1 → 目标加速度 T3
第二层: 加速度误差 e3 → smoothKp0 → jerk 反馈量 d3
```

### 4.7 步骤 7：构造 jerk 指令 _T4

```cpp
_T4.zero();
if (!isZero(e3_length)) {
    Vector3f n = e3 * (1.0f / e3_length);   // 加速度误差方向
    _T4 = n * d3;                            // 反馈项
}
_T4 += T3_1;                                 // + 前馈项
```

**_T4 = 反馈 + 前馈**

- **反馈项** `n × d3`：「x3 还没追上 T3，需要多大的 jerk 去追」
- **前馈项** `T3_1`：「T3 本身在变化，需要额外的 jerk 跟上」

**类比**：
- 反馈项 = 你发现限速变了，踩油门去追新速度
- 前馈项 = 你预见到前方路段限速在持续变化，提前调整油门

### 4.8 步骤 8：欧拉积分更新状态

```cpp
_x1 += _x2 * dt;    // 角度积分（备用，控制律未直接使用）
_x2 += _x3 * dt;    // 角速度积分 ← 控制律的期望角速度
_x3 += _T4 * dt;    // 角加速度积分 ← 控制律的前馈加速度

return _x2;          // 返回平滑后的期望角速度
```

**为什么用欧拉积分而不是更精确的积分方法？**
- 控制周期很短（~4ms，250Hz），欧拉积分足够精确
- 计算量最小，适合嵌入式实时运行
- 误差会在下一周期被反馈修正

## 五、完整数据流图

把上面所有步骤串起来：

```
expect (期望角速度，可能含阶跃)
  │
  ▼
┌─────────────────── 第一层：速度跟踪 ───────────────────┐
│                                                        │
│  e2 = expect - _x2       (速度误差向量)                 │
│  |e2| = √(e2·e2)         (误差模长)                    │
│  d|e2|/dt = (e2·ė2)/|e2| (模长导数)                    │
│  d2 = smoothKp1(|e2|...) (非线性增益 + 导数)            │
│  n = e2/|e2|              (误差方向)                    │
│  T3 = n × d2.d0          (目标加速度向量)               │
│  T3_1 = n×d2.d1 + n_1×d2.d0  (T3的时间导数)            │
│                                                        │
└────────────────────────────────────────────────────────┘
  │ T3, T3_1
  ▼
┌─────────────────── 第二层：加速度跟踪 ─────────────────┐
│                                                        │
│  e3 = T3 - _x3            (加速度误差)                  │
│  d3 = smoothKp0(|e3|...)   (非线性增益)                 │
│  反馈 = (e3/|e3|) × d3                                 │
│  _T4 = 反馈 + T3_1         (jerk = 反馈 + 前馈)         │
│                                                        │
└────────────────────────────────────────────────────────┘
  │ _T4
  ▼
┌─────────────────── 欧拉积分 ──────────────────────────┐
│                                                        │
│  _x3 += _T4 × dt          (加速度积分)                  │
│  _x2 += _x3 × dt          (角速度积分) → 输出给控制律    │
│  _x1 += _x2 × dt          (角度积分，备用)              │
│                                                        │
└────────────────────────────────────────────────────────┘
```

## 六、参数说明

| 参数 | 变量 | 含义 | 效果 |
|------|------|------|------|
| RATE_TD_P1 | _P1 | 第一层增益（当前未使用） | — |
| RATE_TD_P2 | _P2 | 速度层 smoothKp 增益 | 越大 → x2 追 expect 越快 |
| RATE_TD_P3 | _P3 | 加速度层 smoothKp 增益 | 越大 → x3 追 T3 越快 |
| — | _r3 | 速度层饱和半径（硬编码 1e12） | 加速度上限（当前极大≈不限） |
| — | _r4 | 加速度层饱和半径（硬编码 1e12） | jerk 上限（当前极大≈不限） |

### 参数调节建议

- **P2 增大**：跟踪更快，但可能引起 x3 输出抖动
- **P3 增大**：加速度跟踪更快，但 jerk 更大，电机负担更重
- **r3/r4 减小**：限制最大加速度/jerk，使轨迹更柔和（目前硬编码为 1e12，相当于不限制）
- 一般先调 P2（速度跟踪带宽），再调 P3（加速度跟踪带宽）

## 七、一个数值例子

假设 Roll 轴期望角速度突然从 0 跳到 2 rad/s，Pitch/Yaw 保持 0。

**参数**：P2 = 10, P3 = 20, r3 = r4 = 1e12

### 第 1 个周期 (dt = 0.004s)

```
初始状态: _x2 = [0,0,0], _x3 = [0,0,0]

e2 = [2,0,0] - [0,0,0] = [2, 0, 0]
|e2| = 2
e2_1 = -_x3 = [0, 0, 0]
e_1 = 0  (误差没在变，因为 x3=0)

d2.d0 = 1e12 × tanh(10/1e12 × 2) ≈ 1e12 × (20/1e12) = 20
  → 因为 r 极大，tanh(x)≈x，所以 d2.d0 ≈ P2 × |e2| = 10 × 2 = 20
d2.d1 = 0  (因为 e_1 = 0)

n = [1, 0, 0]   (误差全在 Roll 方向)
T3 = [20, 0, 0]  (Roll 方向需要 20 rad/s² 的加速度)

e3 = T3 - _x3 = [20, 0, 0]
d3 = smoothKp0(20, 20, 1e12) ≈ P3 × |e3| = 20 × 20 = 400
_T4 = [400, 0, 0]  (jerk = 400 rad/s³)

积分更新:
_x3 += [400,0,0] × 0.004 = [1.6, 0, 0]   ← 加速度从 0 变到 1.6
_x2 += [0,0,0]   × 0.004 = [0, 0, 0]     ← 角速度还没变（x3 要到下一周期才体现）
```

### 第 2 个周期

```
e2 = [2,0,0] - [0,0,0] = [2, 0, 0]  (x2 还没变)
e2_1 = -_x3 = [-1.6, 0, 0]  (误差正在减小！因为 x3>0 → x2 在增大)
e_1 = (e2·e2_1)/|e2| = (2×(-1.6))/2 = -1.6  (模长在减小)

d2.d0 ≈ 20   (误差模长还是 2)
d2.d1 = P2 × sech²(...) × (-1.6) ≈ 10 × 1 × (-1.6) = -16  (在减小)

T3 ≈ [20, 0, 0]

e3 = [20,0,0] - [1.6,0,0] = [18.4, 0, 0]
d3 ≈ P3 × 18.4 = 368
_T4 = [368, 0, 0] + T3_1

_x3 += [~368,0,0] × 0.004 ≈ [1.6+1.47, 0, 0] = [3.07, 0, 0]
_x2 += [1.6,0,0]  × 0.004 = [0.0064, 0, 0]   ← 角速度开始增大！
```

### 趋势

```
_x2 (Roll 角速度)
2.0 ┤                        ──────────
    │                     ╱
    │                  ╱
    │               ╱
    │            ╱
    │         ╱        ← 中间快速追踪
    │      ╱
    │   ╱              ← 开始缓慢加速
  0 ┤──╱
    └──────────────────────────────→ 时间
       0    0.05   0.1   0.15   0.2

特点: 无超调，S型曲线，先加速后减速
```

## 八、为什么 TD 是三阶而不是二阶？

### 二阶 TD

```
ẋ1 = x2
ẋ2 = 控制量
```

问题：x2 的导数（加速度）可以突变 → 虽然角速度平滑，但**加速度不平滑** → 力矩抖动

### 三阶 TD（本代码）

```
ẋ1 = x2
ẋ2 = x3
ẋ3 = T4（控制量作用在第三层）
```

优势：
- x2（角速度）平滑 ✓
- x3（加速度）也平滑 ✓（因为 x3 是积分出来的）
- **力矩输出平滑**，电机不会突然受力 ✓

**代价**：多了一层计算，稍慢一些（但在 250Hz 下完全可以接受）

## 九、TD 在控制系统中的位置

```
                        ┌──────────┐
  姿态控制器 ──rate_sp──→│   TD     │──x2(平滑角速度)──→ 控制律 Tv1
  或 ACRO 模式          │ track2() │──x3(期望加速度)──→ 控制律 Tv1, Tv2
                        └──────────┘

  控制律使用方式（rate_control.cpp 中）:
    Tv1 = P1 × (TD.x2 - ESO.z1) + TD.x3
          ─────────────────────   ───────
          速度误差×反馈增益        加速度前馈

  如果没有 TD:
    - 直接用 rate_sp 跟踪 → 阶跃导致巨大 Tv1 → 力矩饱和 → 振荡
  有了 TD:
    - rate_sp → 平滑的 x2 → 误差渐进变化 → Tv1 平稳 → 无振荡
    - 额外输出 x3 → 前馈加速度 → 更快响应（不用等误差积累）
```

## 十、常见问题

### Q1: 为什么 _r3 和 _r4 设成 1e12 这么大？

1e12 作为 smoothKp 的饱和半径，意味着输出几乎不会饱和。此时 `tanh(P/r × e) ≈ P/r × e`（因为 P/r 极小），smoothKp 退化为**纯线性增益**：`输出 ≈ P × e`。

这说明当前的 TD 实际上是**线性模式**，非线性限幅特性被关闭了。如果需要限制最大加速度/jerk，可以减小 r3/r4。

### Q2: _x1 为什么没有被控制律使用？

_x1 是角度的积分，在角速度控制环中不需要。它存在是因为三阶微分方程需要三个状态变量。如果将来扩展到角度环控制，_x1 可能会被用上。

### Q3: 为什么第一层用 smoothKp1（带导数）而第二层用 smoothKp0（不带导数）？

- 第一层的输出 T3 的导数 T3_1 被用作第二层的**前馈项**
- 第二层的输出 _T4 的导数不需要（因为没有第三层了）
- 如果扩展到四阶 TD，第二层也需要带导数

### Q4: landed 时为什么要 reset？

飞行中 TD 会积累状态（x2 接近 expect，x3 有残留加速度）。如果降落后不清零：
- 下次起飞时 x3 ≠ 0 → 产生不期望的加速度 → 起飞不稳
- x2 可能残留上次飞行的值 → 误差计算错误
