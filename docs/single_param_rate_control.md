## 一、问题背景：为什么需要单参数控制

多旋翼飞行器的角速度控制本质上是一个 **"力矩 → 角加速度 → 角速度"** 的过程。传统 PID 需要手动调节 P/I/D 三个参数来应对：
- 执行器响应延迟
- 转动惯量不确定
- 风扰、重心偏移等外部干扰

**单参数控制** 的核心思路是：用 **ESO（扩张状态观测器）** 实时估计出 "系统当前到底在发生什么"，用 **TD（跟踪微分器）** 把 "系统应该做什么" 安排好，最后只需 **一个反馈增益** 就能让系统跟上期望。

---

## 三、系统流程详解

### 3.1 起点：获取输入

每个控制周期，`RateControl::update()` 被调用，接收以下输入：

| 输入 | 变量名 | 来源 | 含义 |
|------|--------|------|------|
| 实际角速度 | `rate` | 陀螺仪 | 飞行器当前转多快 (rad/s) |
| 期望角速度 | `rate_sp` | 姿态控制器 | 飞行器应该转多快 (rad/s) |
| 实际角加速度 | `angular_accel` | 角速度微分估计 | 仅PID的D项使用 |
| 时间步长 | `dt` | 系统时钟 | 本周期时间间隔 (s) |
| 着陆标志 | `landed` | 着陆检测器 | 着陆时重置所有状态 |

三个轴 (Roll/Pitch/Yaw) 在同一个向量中并行处理。

---

### 3.2 第一步：TD 安排 "应该怎么走"

**问题**: 姿态控制器给出的 `rate_sp` 可能是阶跃跳变（比如打杆瞬间从 0 跳到 200°/s），直接跟踪会引起振荡。

**解决**: 用三阶跟踪微分器 (TD3) 把阶跃信号变成平滑轨迹，同时自动生成期望角加速度供前馈使用。

```
输入: rate_sp (可能含阶跃)
                    ┌──────────────────────┐
  rate_sp ────────►│   三阶跟踪微分器 TD3   │
                    │                      │
                    │  核心: 非线性增益      │
                    │  d = r·tanh(P/r·|e|) │
                    │                      │
                    │  状态积分:            │
                    │  x1 += x2·dt         │
                    │  x2 += x3·dt         │
                    │  x3 += T4·dt         │
                    └──┬──────────┬────────┘
                       │          │
                       ▼          ▼
                x2 = 平滑后的    x3 = 期望
                  期望角速度      角加速度
```

**工作原理**:
1. 计算 `e2 = rate_sp - x2`（期望与跟踪值的差）
2. 通过 `tanh` 非线性增益函数计算目标加速度 `T3 = direction × r·tanh(P2/r × |e2|)`
   - 小误差时增益 ≈ P2（线性快速跟踪）
   - 大误差时增益趋于 r（饱和限幅，防止过冲）
3. 再做一层加速度跟踪：`T4 = direction × r·tanh(P3/r × |e3|) + Ṫ3`
4. 三层状态依次积分：`x3 += T4·dt`, `x2 += x3·dt`, `x1 += x2·dt`

**输出**: `x2`（平滑期望角速度）和 `x3`（期望角加速度），这两个量将在控制律中使用。

**参数**: `RATE_TD_P2`（速度跟踪带宽）、`RATE_TD_P3`（加速度跟踪带宽），默认都是 50。

---

### 3.3 第二步：ESO 看清 "实际发生了什么"

**问题**: 陀螺仪只给了角速度，但控制律需要知道角加速度、外部扰动、执行器实际响应——这些都不直接可测。

**解决**: ESO 扩张状态观测器从陀螺仪测量和上一周期的控制输入，估计出完整的系统状态。

每轴各有一个独立的 ESO，以 Roll 轴为例：

```
上一周期控制输出 u ─────────────────────────────────────┐
                                                         │
                                                         ▼
                                            ┌───────────────────────┐
                                            │ 执行器惯性模型 (开环)   │
                                            │ z_i += dt/T·(b·u-z_i) │
                                            └───────────┬───────────┘
                                                        │ z_inertia
陀螺仪测量 v ──┐                                        │ (控制输入产生的角加速度)
               │    ┌───────────────────────┐           │
               │    │    观测误差计算         │           │
               ├───►│ err = v - his_z1[0]   │           │
               │    │ (测量 - 8步前估计)     │           │
               │    └───────────┬───────────┘           │
               │                │                        │
               │                ▼                        │
               │    ┌───────────────────────┐           │
               │    │    自适应增益          │           │
               │    │ 误差同方向持续越久     │           │
               │    │ → 扰动增益越大        │           │
               │    │ scale = 1+ζ₂·t³      │           │
               │    └───────────┬───────────┘           │
               │                │                        │
               │                ▼                        │
               │    ┌───────────────────────┐           │
               │    │    状态校正            │           │
               │    │ z1 += β₁·err (角速度) │           │
               │    │ z2 += β₂·Δerr (扰动) │           │
               │    │ + 历史队列回溯补偿     │           │
               │    └───────────┬───────────┘           │
               │                │                        │
               │                ▼                        │
               │        ┌──────────────┐                │
               │        │  ESO 输出     │                │
               │        │  z1: 角速度估计│                │
               │        │  z2: 扰动估计  │◄──────────────┘
               │        │  z_i: 惯性响应 │
               │        │  α = z_i + z2 │ (总角加速度)
               │        └──────────────┘
```

**ESO 的两阶段工作循环**:

| 阶段 | 何时调用 | 做什么 | 物理意义 |
|------|---------|--------|---------|
| **闭环校正** `run()` | 周期开始，拿到陀螺仪数据后 | 用测量值修正估计值 | "用观测纠正预测偏差" |
| **开环预测** `updateControlInput()` | 周期结束，控制输出确定后 | 用控制输出预测下一步 | "根据施加的力预测运动" |

**8步历史队列的意义**: 陀螺仪到 ESO 之间有滤波延迟（约 8 个采样周期）。ESO 不是拿当前估计值去和测量值比，而是拿 8 步前的历史估计值（`his_z1[0]`）去比——这样延迟就被补偿了。校正量会回溯更新整个历史队列。

**自适应增益**: 如果观测误差持续同方向增长，说明可能有未补偿的扰动，ESO 会自动增大扰动观测增益 β₂（最高 5 倍），加快扰动跟踪速度。

**ESO 参数** (每轴独立):

| 参数 | QGC 参数名 | 物理含义 | 默认值 |
|------|-----------|---------|--------|
| β₁ | `RATE_ESO{R/P/Y}_BETA1` | 角速度校正增益，越大跟踪越快但越易受噪声 | 0.6 |
| β₂ | `RATE_ESO{R/P/Y}_BETA2` | 扰动校正增益，越大扰动响应越快 | 7.0 |
| ζ₂ | `RATE_ESO{R/P/Y}_CETA2` | 自适应系数，越大增益自适应越激进 | 5000 |
| T | `RATE_ACT_T_{R/P/Y}` | 执行器一阶惯性时间常数 | 0.07 s |
| b | `RATE_ACT_B_{R/P/Y}` | 控制输入到角加速度的增益 | 120/100/100 |

### 3.4 第三步：控制律 "算出该给多少力矩"

TD 告诉我们 "期望轨迹"，ESO 告诉我们 "当前状态"，现在控制律计算它们之间的差距，得出需要的力矩。

以 Roll 轴为例，记号：
- `x2`, `x3` — TD 输出（期望角速度、期望角加速度）
- `z1` — ESO 估计角速度
- `α_eso = z_inertia + z2` — ESO 估计总角加速度
- `P1`, `P2` — 反馈增益 (`RATE_FEED_R_P1`, `RATE_FEED_R_P2`)

```
  ╔══════════════════════════════════════════════════════════════════╗
  ║  第一层：速度误差反馈 + 加速度前馈                                ║
  ║                                                                  ║
  ║    Tv1 = P1 × (x2 - z1) + x3                                   ║
  ║          ────────────────   ──                                   ║
  ║          速度误差×增益      加速度前馈                             ║
  ║                                                                  ║
  ║    含义: "角速度差这么多，需要这么大的角加速度去追"                  ║
  ╚══════════════════════════════════════════════════════════════════╝
                                │ Tv1 (期望角加速度)
                                ▼
  ╔══════════════════════════════════════════════════════════════════╗
  ║  第二层：加速度误差反馈                                          ║
  ║                                                                  ║
  ║    Tv2 = P2 × (x3 - α_eso)                                     ║
  ║          ──────────────────                                      ║
  ║          加速度误差×增益                                          ║
  ║                                                                  ║
  ║    含义: "角加速度差这么多，需要这么大的 jerk 去追"                 ║
  ╚══════════════════════════════════════════════════════════════════╝
                                │ Tv2 (期望jerk)
                                ▼
  ╔══════════════════════════════════════════════════════════════════╗
  ║  合成：总角加速度指令                                            ║
  ║                                                                  ║
  ║    Ta1 = P2 × (Tv1 - α_eso) + Tv2                              ║
  ║                                                                  ║
  ║    含义: 把速度层和加速度层的控制量叠加                            ║
  ╚══════════════════════════════════════════════════════════════════╝
                                │ Ta1 (角加速度指令)
                                ▼
  ╔══════════════════════════════════════════════════════════════════╗
  ║  力矩输出：执行器模型反解 + 扰动补偿                              ║
  ║                                                                  ║
  ║    飞行中: torque = (z_inertia + T × Ta1) / b                   ║
  ║                      ─────────   ────────   ─                    ║
  ║                      扰动补偿    执行器反解  增益归一化            ║
  ║                                                                  ║
  ║    着陆时: torque = (T × Ta1) / b                                ║
  ║           (去掉扰动补偿项，防止地面振荡)                           ║
  ╚══════════════════════════════════════════════════════════════════╝
                                │
                                ▼
                        torque_acfly_setpoint
```

**为什么叫 "单参数"**: 当 P1 = P2 时，整个控制律实质上只有一个可调增益。ESO 自动补偿了模型不确定性和外扰，TD 自动安排了过渡过程，控制律只需要一个 "追踪快慢" 的旋钮。

**Yaw 轴的特殊处理**: Yaw 轴在飞行中不加惯性补偿项 `z_inertia`，直接用 `Ta1/b`，因为 Yaw 轴的扰动特性不同（主要是反扭矩）。

**反馈增益参数**:

| 参数 | Roll | Pitch | Yaw | 默认值 |
|------|------|-------|-----|--------|
| P1 (速度层) | `RATE_FEED_R_P1` | `RATE_FEED_P_P1` | `RATE_FEED_Y_P1` | 15.0 |
| P2 (加速度层) | `RATE_FEED_R_P2` | `RATE_FEED_P_P2` | `RATE_FEED_Y_P2` | 15.0 |

---

### 3.5 并行路径：传统 PID

与单参数控制律并行，传统 PID 也在同时运算：

```
torque_pid = Kp × (rate_sp - rate)        // 比例
           + integral                      // 积分
           - Kd × angular_accel            // 微分 (用角加速度)
           + Kff × rate_sp                 // 前馈
```

积分器具有三重保护：
1. **控制分配饱和反馈** — 输出饱和时停止积分
2. **非线性衰减** — `i_factor = max(0, 1 - (error/400°)²)`，大误差时积分自动弱化
3. **硬限幅** — `constrain(-lim, +lim)`

PID 始终运行，以便随时可切换回传统模式。

---

### 3.6 选择输出：模式选择器

参数 `RATE_CTRL_MODE` 决定每轴力矩来自 ESO 还是 PID：

```
              torque_acfly (ESO输出)     torque_pid (PID输出)
                      │                        │
                      ▼                        ▼
               ┌──────────────────────────────────────┐
               │         RATE_CTRL_MODE               │
               │                                      │
               │  模式0: [PID] [PID] [PID]  ← 传统    │
               │  模式1: [ESO] [PID] [PID]  ← Roll验证 │
               │  模式2: [PID] [ESO] [PID]  ← Pitch验证│
               │  模式3: [PID] [PID] [ESO]  ← Yaw验证  │
               │  模式4: [ESO] [ESO] [PID]  ← 双轴验证 │
               │  模式5: [ESO] [ESO] [ESO]  ← 全ESO    │
               │        Roll  Pitch  Yaw              │
               └──────────────────┬───────────────────┘
                                  │
                                  ▼
                           torque_setpoint
```

**设计意图**: 逐轴递进验证。先在 Roll 单轴上调通 ESO，确认效果后扩展到 Pitch，最后 Yaw，降低调试风险。

---

### 3.7 收尾：更新积分器 & ESO 预测

控制输出确定后，还有两件事要做：

**① 更新 PID 积分器** (仅飞行中)
```
_rate_int += i_factor × Ki × rate_error × dt
```

**② ESO 开环预测** — 把本周期实际输出的力矩告诉 ESO
```
acfly_eso_roll.updateControlInput(torque_setpoint(0));
acfly_eso_pitch.updateControlInput(torque_setpoint(1));
acfly_eso_yaw.updateControlInput(torque_setpoint(2));
```

这一步完成后，ESO 内部的 `z_inertia` 和 `z1` 就已经 **预测到了下一周期** 的状态。下一次 `run()` 调用时，ESO 会用新的陀螺仪测量值来校正这个预测，形成闭环。

```
时间 ──────────────────────────────────────────────────────────────────►

 [获取输入]          [并行计算]                    [选择&收尾]
     │                  │                              │
     │    ┌─────────────┼──────────────────┐          │
     │    │             │                  │          │
     ▼    ▼             ▼                  ▼          ▼
  ┌─────┐ ┌──────┐  ┌──────┐  ┌─────────┐ ┌──────┐ ┌──────────┐ ┌──────┐
  │获取  │ │ ESO  │  │ TD   │  │单参数   │ │ PID  │ │模式选择  │ │ESO   │
  │rate │→│闭环  │→ │跟踪  │→ │控制律   │ │计算  │→│→输出    │→│开环  │
  │rate_│ │校正  │  │微分  │  │Tv1→Ta1 │ │      │ │torque  │ │预测  │
  │sp   │ │      │  │      │  │→torque  │ │      │ │setpoint│ │      │
  └─────┘ └──────┘  └──────┘  └─────────┘ └──────┘ └──────────┘ └──────┘
     ①       ②         ③          ④          ⑤         ⑥          ⑦

  ①  从 uORB 获取陀螺仪数据和角速度期望值
  ②  ESO 用陀螺仪测量校正上一周期的预测 → 得到 z1, z2, z_inertia
  ③  TD 对 rate_sp 做平滑跟踪 → 得到 x2, x3
  ④  控制律用 TD 和 ESO 的输出计算 ESO 力矩
  ⑤  传统 PID 并行计算 PID 力矩
  ⑥  根据 RATE_CTRL_MODE 选择各轴输出，更新积分器
  ⑦  ESO 接收最终力矩输出，做开环预测，为下一周期准备
```
