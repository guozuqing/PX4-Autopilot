# 16轴同轴电机配置文档

## 概述

本文档描述了PX4固件中16轴同轴多旋翼飞机（Coaxial Hexadecacopter）的电机配置方案。该机型基于8轴X型布局（8001_octo_x），在每个电机位置增加一个倒置安装的电机，形成上下两层共16个电机的同轴布局。

## 机型信息

| 项目 | 值 |
|-----|---|
| 机型名称 | Coaxial Hexadecacopter X |
| 机型ID | 10001 |
| MAV_TYPE | 14 (Octorotor) |
| 电机数量 | 16 |
| 配置文件 | `ROMFS/px4fmu_common/init.d/airframes/10001_hexadeca_x` |

## 参数说明

### 位置参数

- **PX**: 电机相对于重心的前后位置（正值=前方，负值=后方）
- **PY**: 电机相对于重心的左右位置（正值=左侧，负值=右侧）
- **PZ**: 电机相对于重心的上下位置（负值=上方，正值=下方）

### 力矩系数 KM

- **KM > 0 (正值)**: 电机逆时针旋转 (CCW)，产生顺时针偏航力矩
- **KM < 0 (负值)**: 电机顺时针旋转 (CW)，产生逆时针偏航力矩

### 同轴对旋原理

每对同轴电机（如M1/M9）：
- 位置相同（PX, PY相同）
- 上下分层（PZ符号相反）
- 旋转方向相反（KM符号相反）
- 扭矩相互抵消，提高偏航控制效率

## 使用方法

### 1. 选择机型

在QGroundControl中：
1. 进入 **Vehicle Setup > Airframe**
2. 选择 **Octorotor Coaxial** 类别
3. 选择 **Coaxial Hexadecacopter X geometry (16 rotors)**
4. 点击 **Apply and Restart**

### 2. 通过参数设置

```bash
# 设置机型
param set SYS_AUTOSTART 10001
reboot
```

### 3. 验证配置

```bash
# 查看电机配置
param show CA_ROTOR*

# 测试单个电机
actuator_test set -m 1 -v 0.1    # 测试M1
actuator_test set -m 9 -v 0.1    # 测试M9
actuator_test set -m 1 -v -1     # 停止
```

## 注意事项

1. **电机安装方向**
   - 上层电机：正常安装，螺旋桨推力向下
   - 下层电机：倒置安装，螺旋桨推力向上

2. **螺旋桨选择**
   - 上层CW电机使用CW螺旋桨
   - 上层CCW电机使用CCW螺旋桨
   - 下层电机螺旋桨方向与上层对应电机相反

3. **ESC校准**
   - 所有16个ESC需要统一校准
   - 建议使用相同型号和固件版本的ESC

4. **功率要求**
   - 16电机系统功率需求较高
   - 确保电池和配电板能够提供足够电流
